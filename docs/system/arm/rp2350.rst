Raspberry Pi RP2350 (``rp2350``)
================================

The RP2350 is a dual-core microcontroller from Raspberry Pi Ltd. This
machine models its Arm configuration: two Cortex-M33 cores with the
Security Extension, FPU, DSP extension, and 52 external interrupts, plus
520 KiB of SRAM. The cores' MPU region counts are QEMU's defaults.

Supported devices
-----------------

* Boot ROM (32 KiB at ``0x00000000``)
* XIP flash at ``0x10000000``, with its non-caching aliases. The chip has
  no flash of its own, so the board sets its size with
  ``-M rp2350,flash-size=SIZE`` (up to 16 MiB; a Pico 2 has 4 MiB). There
  is no default.
* SRAM (520 KiB at ``0x20000000``; ``-m`` cannot change it)

Modelled peripherals:

* RESETS, CLOCKS, XOSC, PLL_SYS, PLL_USB and TICKS, enough for the status
  bits software waits on (clock frequencies are not modelled)
* SIO: CPUID, inter-core FIFOs, spinlocks, doorbells and GPIO registers,
  in separate Secure and Non-secure banks
* TIMER0 and TIMER1
* UART0 and UART1 (PL011) on the first two serial ports
* The MPU, with eight Secure and eight Non-secure regions per core

Every other peripheral block in the address map is an unimplemented
device. Core 1 starts powered off. With ``-kernel``, the machine plays core
1's side of the boot ROM launch handshake over the SIO FIFO, so software
starts core 1 as it would on hardware (for example with pico-sdk's
``multicore_launch_core1()``).

Boot options
------------

At least one of these must be given:

``-bios FILE``
  Loads a raw boot ROM image at ``0x00000000``. Core 0 resets through the
  ROM's vector table, as on hardware.

``-kernel FILE``
  Loads an ELF image, or a raw image into flash, so ``flash-size`` must be
  set. Core 0 resets through the vector table at ``0x10000000``, skipping
  the boot ROM. Images loaded this way must place their vector table at
  the start of flash. If ``-bios`` is given as well, the ROM is mapped, so
  ROM function-table lookups work, but it is not executed.

The boot ROM is not distributed with QEMU. It can be built from Raspberry
Pi's published source, https://github.com/raspberrypi/pico-bootrom-rp2350.

.. code-block:: bash

  $ qemu-system-arm -M rp2350,flash-size=4M -kernel kernel.elf -nographic
